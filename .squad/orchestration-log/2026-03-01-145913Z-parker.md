## Decisions Made

**Role Scoping:**
- Web: `Storage Blob Data Reader` (read-only, serves logos)
- API: `Storage Blob Data Contributor` (upload/read/delete)
- Functions: `Storage Blob Data Contributor` (process blobs)
- Jobs: _(none)_ — no blob interaction in current design

**Infrastructure Pattern:**
- Use `azurerm_role_assignment` loop in `infra/modules/storage/rbac.tf`
- Accept three identity principal IDs from root module via variables
- Use `uuidv5` for deterministic role assignment names (prevents drift)

**Configuration:**
- Storage account name: non-secret App Configuration value (per-environment label)
- No `Storage-ConnectionString` in Key Vault
- No SAS token generation anywhere

## Decisions Made

**Interface Design:**
- `IBlobStorageService` is the abstraction; all service projects call through it
- No `GenerateSasUri`, no `GetSasUri`, no SAS-related methods
- Plain blob URIs returned; callers get `Uri` object without query params

**Aspire Wiring:**
- Use `builder.AddAzureStorageBlobs("blob-storage")` registration in Infrastructure DI
- Aspire.Azure.Storage.Blobs package provides DefaultAzureCredential integration
- Aspire.Hosting.Azure.Storage package required in AppHost for emulator + resource modeling

**NuGet Dependencies:**
- Infrastructure: `Azure.Storage.Blobs` + `Aspire.Azure.Storage.Blobs`
- AppHost: `Aspire.Hosting.Azure.Storage`

**Configuration Pattern:**
- Development: Aspire injects Azurite connection string from `AddAzureStorage().RunAsEmulator()`
- Production: Aspire uses ServiceUri from appsettings + DefaultAzureCredential picks up managed identity

**RBAC Dependencies:**
- Container App (API): requires `Storage Blob Data Contributor` from Parker's Terraform
- Container Apps Workers: requires `Storage Blob Data Contributor` from Parker's Terraform
- Local dev: no credentials needed; Azurite is unauthenticated
